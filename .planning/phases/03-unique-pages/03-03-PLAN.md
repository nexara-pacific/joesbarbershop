**Pre-flight:**
1. `firecrawl --status` — confirm authenticated, credits ≥ 30 remaining.
2. `mkdir -p .firecrawl`.

**Step 1 — Discovery search** (per RESEARCH § Pattern 8):

Run primary query:
- `firecrawl search "best barbershops near 723 E Bradley Ave El Cajon CA" --scrape --limit 8 -o .firecrawl/competitor-search.json --json`

If first query returns Joe's only or fewer than 5 unique businesses, try alternates:
- `firecrawl search "barbershop El Cajon CA reviews" --scrape --limit 8 -o .firecrawl/competitor-search-alt1.json --json`
- `firecrawl search "top rated barbershop Bostonia East County" --scrape --limit 8 -o .firecrawl/competitor-search-alt2.json --json`

**Step 2 — Extract candidate URLs** (filter out non-business pages):

`jq -r '.data.web[].url' .firecrawl/competitor-search.json`

Identify 5–8 URLs that are Yelp business pages, Google Maps places, or barbershop-website root pages. EXCLUDE: news articles, third-party listicles, Joe's own pages.

**Step 3 — Scrape each candidate URL** (target 5–7 to leave headroom for Step 4 filter):

For each URL `$U` and a slug-form `$N` (e.g. `firstcuts-el-cajon`):

`firecrawl scrape "$U" --only-main-content -o ".firecrawl/competitor-${N}.md"`

If a scrape returns < 50 lines OR no name/address/rating signal (`grep -E "★|review|rating|address" $FILE | wc -l` returns < 5), retry once with `--wait-for 3000`. After 1 retry, drop that candidate and move on.

**Retry budget enforcement (D-14 specifics):** maximum 3 attempts on the discovery search; per-candidate retries capped at 1 each. After all retries exhausted, count usable scrapes — Task 2 decides path A (≥3 real with usable NAP) or path B (D-14 hybrid).

**Pass-through:** This task succeeds if Steps 1–3 produced ANY scraped competitor markdown files (even 1). Task 2 handles the count gate and fallback.

Reference: D-13, D-14 (fallback), RESEARCH § Pattern 8, Pitfall 7.
