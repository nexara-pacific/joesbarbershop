<task type="auto">
  <name>Task 2: Write audit.sh suite</name>
  <files>.planning/phases/03-unique-pages/scripts/audit.sh</files>
  <action>
Create `.planning/phases/03-unique-pages/scripts/audit.sh`. Make it executable (`chmod +x`).

Script must be a Bash script (`#!/usr/bin/env bash`) with `set -euo pipefail`. Top-level usage:
- `bash audit.sh` — runs ALL checks against `site/dist/` and `site/src/`. Exits 0 only if all pass.
- `bash audit.sh --check <name>` — runs single named check. Names: `bluf-position`, `cost-guide-slugs`, `no-client-directives`, `no-anti-patterns`, `no-accordions`, `homepage-faq`, `niche-faq`, `niche-areaserved`, `cost-guide-entries`, `about-staff-names`, `about-pending-photos`, `reviews-cards`, `reviews-sources`, `faq-master-count`.
- `bash audit.sh --self-test` — sanity-checks the script itself (verifies tools available: grep, wc, sort, head; verifies `site/dist/` exists OR prints "BUILD FIRST" and exits non-zero).

Each check is a Bash function. Failure prints one line `FAIL: <check-name> — <assertion>` and increments a failure counter. After all checks run (when no `--check` filter), print summary: `audit complete: N passed, M failed`. Exit 1 if any failed, 0 otherwise.

**Use `grep -v '^#' | grep -c token` style for any HTML count gates that might match comments** (per planner agent's grep gate hygiene rule). For built `site/dist/*.html` HTML, grep can match raw — Astro strips comments by default — but defensive filtering is fine.

**Required check implementations** (all read from `site/dist/<page>/index.html` unless noted):

1. `homepage-faq`: `grep -c '<article class="faq-q"' site/dist/index.html` — expect 5 or 6. Fail otherwise.
2. `niche-faq`: `grep -c '<article class="faq-q"' site/dist/east-county-traditional-barbershop/index.html` — expect 6. Fail otherwise.
3. `niche-areaserved`: `grep -oE '<a[^>]*href="/[a-z-]+-barber"' site/dist/east-county-traditional-barbershop/index.html | sort -u | wc -l` — expect 5. Fail otherwise.
4. `cost-guide-slugs`: For each slug in `canonical-slugs.txt`, `grep -q "href=\"/${slug}\"" site/dist/2026-east-county-barbershop-cost-guide/index.html`. Fail listing all missing slugs.
5. `cost-guide-entries`: `grep -c '<article class="entry"' site/dist/2026-east-county-barbershop-cost-guide/index.html` — expect ≥ 4. Fail otherwise.
6. `about-staff-names`: `grep -q "Joe Denesowicz" site/dist/about/index.html && grep -q "Alex" site/dist/about/index.html`. Fail if either missing.
7. `about-pending-photos`: `grep -c 'data-pending-photo' site/dist/about/index.html` — expect 2. Fail otherwise.
8. `reviews-cards`: `grep -c '<article class="review-card"' site/dist/reviews/index.html` — expect 6, 7, or 8. Fail otherwise.
9. `reviews-sources`: `grep -oE '(Google|Yelp)' site/dist/reviews/index.html | sort -u | wc -l` — expect 2 (both sources represented). Fail otherwise.
10. `faq-master-count`: `grep -c '<article class="faq-q"' site/dist/faq/index.html` — expect ≥ 10. Fail otherwise.
11. `no-client-directives`: `grep -rE 'client:(load|idle|visible|only)' site/src/pages/ 2>/dev/null | wc -l` — expect 0. Fail with the matching lines if non-zero.
12. `no-anti-patterns`: `grep -irE "(we're more than a barbershop|experience the difference|click here|innovate|streamline|we might|could potentially)" site/src/pages/ 2>/dev/null | wc -l` — expect 0. Fail with lines if non-zero. (Banned phrases per UI-SPEC § Copywriting Contract.)
13. `no-accordions`: `grep -rE "(<details>|aria-expanded|tab-panel|tabpanel)" site/src/pages/ 2>/dev/null | wc -l` — expect 0. Fail with lines if non-zero.
14. `bluf-position`: For each non-homepage built page (`east-county-traditional-barbershop`, `2026-east-county-barbershop-cost-guide`, `about`, `reviews`, `faq`), assert `grep -n '<section class="bluf"' site/dist/<page>/index.html` returns line number that comes BEFORE any `<section class="prose"`, `<section class="entries-section"`, `<section class="reviews-section"`, `<div class="review-grid"`, or first `<article class="faq-q"`. The BLUF must be the first content block under `<main>`.

**Self-test (`--self-test`) function**:
- Verify `command -v grep`, `command -v sort`, `command -v wc` all return 0.
- Verify `site/` directory exists.
- If `site/dist/` does not exist, print `BUILD FIRST: cd site && npm run build` and exit 1.
- Verify `canonical-slugs.txt` exists in same dir as the script and has 11 lines.
- Print `self-test passed` and exit 0 on success.

**No-arg call** (default = run all checks): runs every check above in order. Skip a check (with a `SKIP: <check-name> — page not built yet` line, do not count as fail) if its target HTML file does not exist. This lets the script run mid-phase before all 6 pages exist.

Reference VALIDATION.md § Per-Task Verification Map for the source-of-truth assertion list. Each row in that table maps to a `--check` name above.
