<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local machine -> Vercel CDN | Code uploaded to Vercel for hosting; project link persists in `site/.vercel/project.json` (must be gitignored — contains `projectId`/`orgId`) |
| Vercel preview URL -> public internet | Preview URLs are unguessable but technically public (anyone with the URL can fetch); shareable with Joe but not search-indexed unless we link to it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04-01 | Information Disclosure | Project link file accidentally committed exposes `projectId`/`orgId` | mitigate | Task 1 ensures `.vercel/` is added to `site/.gitignore`. The IDs alone are not credentials but are best kept out of public repos. Verify with `git status` before any commit in this phase. |
| T-01-04-02 | Spoofing | Wrong Vercel account/team hosts the preview (e.g., uses client account for sandbox project) | mitigate | Task 1 runs `vercel whoami` and `gh auth status` and PAUSES at a checkpoint where the human confirms the scope. Per MEMORY.md, Joe's Barbershop is a personal sandbox — should land on DarrellTang's personal scope, NOT `darrell-tang-consulting`. |
| T-01-04-03 | Elevation of Privilege | Accidental `vercel --prod` deploys before Joe approves, putting the placeholder/stub site on a production domain | mitigate | Acceptance criterion explicitly forbids `--prod` flag. Project constraint in CLAUDE.md is "no live deployment before Joe approves." Phase 6 is the only phase allowed to consider production deploy. |
| T-01-04-04 | Information Disclosure | Phase 1 stub copy ("Phase 2: util-bar — phone, hours, walk-ins welcome") leaks scaffolding language on the preview URL | accept | Preview URL is shared with Joe only via direct link (per project constraint, no public marketing). Phase 2 replaces the stub copy. Risk is informational. |
| T-01-04-05 | Information Disclosure | Sitemap-index.xml served from the preview URL exposes the placeholder `site:` value (`https://joesbarbershop.vercel.app`) and could be crawled if discovered | accept | The placeholder host may not exist; if a crawler dereferences it, it gets a 404. Phase 6 updates `site:` to the real preview URL before showcase. No PII or secrets at risk. |
</threat_model>
